Distribusi aman

Upload APK

Server 1 mengunggah APK staging ke GitHub Release; Server 2 menyimpan URL APK yang ditempel. Token Blob dan GitHub hanya dipakai server-side.

Rilis aplikasi

Unggah APK memerlukan akun dengan role Owner. Jika masuk memakai Owner Key, masukkan kredensial Owner saat diminta. Batas file 120 MiB.

Full release membuka halaman unduhan website; varian APK langsung membuka berkas yang dipilih.

Berkas akan dipindahkan ke GitHub Releases; unggahan sementara Blob akan dihapus setelah berhasil.

Pastikan nama versi dan version code sama dengan APK yang akan dirilis.
